# Agente Autónomo

A small starter design system for Agente Autónomo. The source repository held only a README and no styles, components or assets, so nothing could be extracted: these tokens are a deliberate first draft to be replaced by real values once the product has UI.

## Content fundamentals
Plain, calm, direct. Describe what the agent did or will do in the active voice ("Task completed", "Needs your approval"). Sentence case everywhere; no exclamation marks.

## Visual foundations
- **Colour:** a cool neutral ground (`surface`) with `ink` text, a single blue `brand` for primary actions, and `accent` orange reserved for large decorative areas. `success` and `danger` carry state only.
- **Type:** Inter (system fallback) for interface text, `code` in the monospace stack for logs and commands.
- **Space and shape:** a 4px base (`space-1` to `space-6`); `radius-md` for buttons, `radius-lg` for cards.
- **Pattern:** a dot grid at `space-4` pitch signals precision and methodical work.

## Iconography
None yet. Use plain text labels until an icon set is chosen.
