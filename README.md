# agente-autonomo
## Open Generative AI (imagen, video, lip sync, cinema)

Instalación: `./scripts/install-open-generative-ai.sh` (requiere Node 20+).
Uso: `cd tools/open-generative-ai && npm run dev` → http://localhost:3000
Necesitas una API key de [Muapi.ai](https://muapi.ai/access-keys) (se introduce en la app).
`tools/` está en `.gitignore`.

## Respaldo gratis para Claude Code (FreeLLMAPI)
Skill: `.claude/skills/freellm-fallback`. Instalar: `scripts/freellm-setup.sh`; usar: `scripts/claude-free`.
